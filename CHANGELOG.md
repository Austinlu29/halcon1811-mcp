# Changelog

## 0.1.0 — 2026-10-09

- Package the HALCON 18.11 integration as an installable Python project.
- Expose local operator documentation, program saving/loading, execution and status tools over stdio MCP.
- Save code, user requirements and analysis in separate version directories.
- Keep generated data in a user data directory rather than site-packages.
- Include a threshold demonstration CLI and an optional Tkinter interface.
- Validate generation/save behavior and the MCP workflow against HALCON 18.11 on Windows.
